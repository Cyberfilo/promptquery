# PromptQuery brand assets

The mark is a terminal **prompt caret + cursor** (`>_`) in brand green on near-black — the same
geometry as the website favicon. Mirrors [prq.menghi.dev](https://prq.menghi.dev).

## Palette
| Token | Hex | Use |
|---|---|---|
| ink | `#0a0b10` | background |
| line | `#232634` | borders, grid |
| fg | `#e6e9f0` | foreground text |
| **green** | **`#4ee07a`** | the mark, accents, "Query" |
| blue | `#76a9ff` | secondary accent (read-only) |

Type: **JetBrains Mono** (mark / wordmark / code) + **IBM Plex Sans** (body). Wordmark is
`promptQuery` with `Query` in green. Tagline: **"SQL is engineering, not conversation."**

## Files
| File | Purpose |
|---|---|
| `icon.svg` | vector source of truth for the mark |
| `icon-512.png` | raster master |
| `banner.png` | 1500×500 README / social header |
| `og.png` | 1280×640 social card — repo social preview + `og:image` |
| `avatar-400.png` | square avatar (GitHub / X / Reddit) |

## Social preview (one manual step)
GitHub can't set the repo social preview via API. Upload `og.png` at
**Settings → General → Social preview**.
